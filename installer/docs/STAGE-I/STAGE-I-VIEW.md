# Детализация экранов первой итерации разработки

## Общий лейаут каждого экрана:
- Левая панель (Sidebar): Список шагов со статусами: 
    - 🔴 Ошибка/Не заполнено
    - 🟢 Готово
    - 🔵 Активен
    - ⚪ Неактивен
- Нижняя панель (Footer):
    - Кнопка «Назад» слева
    - Кнопка «Далее» справа
    - Кнопка «Далее» неактивна, пока не пройдена валидация текущего шага.
- Центральная область: Контент шага.

## Экран 1: Введение и Режим установки
- Заголовок: "YDB Enterprise Manager Installer".
- Блок информации: Версия инсталлятора, краткое описание возможностей.
- Группа кнопок "Режим установки YDB":
    - Автоматическая установка YDB Cluster (Требует наличия Ansible-файлов).
    - Ручная настройка YDB Cluster (Пошаговый мастер).
- Чекбокс "Доступ в Интернет".
- Статус "Проверка зависимостей".

Логика перехода далее: Только если выбраны режимы и пройдена проверка зависимостей.

## Экран 2: Топология кластера (Схема)
- Группа кнопок "Выбор топологии кластера":
    - 3-nodes-mirror-3-dc (v1):
        - Описание
        - Требования
        - Схематическая картинка
    - 6-nodes-bridge-2-dc (v2):
        - Описание
        - Требования
        - Схематическая картинка

Логика перехода далее: Выбор обязателен.

## Экран 3: Инвентарь хостов (Hosts Inventory)
- Динамическая таблица для каждого ДЦ в зависимости от выбранной схемы на Экране 2.
    - Столбцы каждой таблицы:
        - Hostname / IP
        - Role (Static/Dynamic/Combined)
    - Кнопка "Добавить хост" внизу таблицы

Валидация: Подсветка красным, если количество хостов не соответствует выбранной схеме.

Логика перехода далее: Все обязательные поля заполнены, количество хостов валидно.

## Экран 4: Настройки доступа (SSH & Connectivity)
В начале экрана: ping хостов

- Глобальные настройки:
    - Логин пользователя (default: root или ydb).
    - Переключатель "Тип аутентификации": [SSH Key | Пароль].
        - Key: Поле загрузки файла или текстовое поле для вставки ключа.
        - Password: Поле ввода (скрытый ввод).
    - Чекбокс "Использовать Jump-host".
    - Поле ввода FQDN/IP Jump-host: появляется, если чекбокс "Использовать Jump-host" активен, либо хосты недоступны (ping хостов не удался).
- Расширенные настройки: Чекбокс "Своя строка настроек SSH" (открывает текстовое поле для флагов -o StrictHostKeyChecking=no и т.д.).

- Кнопка "Проверить доступность хостов" с проверками:
    - Доступность хостов.
    - Синхронизация времени.
    - Список доступных дисков (pre-scan).

Логика перехода далее: Только если все хосты прошли проверку (зеленый статус). Ошибки должны быть кликабельны для перехода к проблемному хосту.

## Экран 5: Дисковая подсистема
- Таблица хостов (из Экрана 3). При клике на хост раскрывается список обнаруженных дисков.
    - Чекбоксы для выбора рядом с каждым диском.
    - Индикация типа диска (HDD/SSD/NVMe) и размера.
    - Предупреждение, если диск уже смонтирован или содержит файловую систему.

Логика перехода далее: У каждого узла хранения (Storage Node) выбран хотя бы один диск.

## Экран 6: Версия и Дистрибутив

- Переключатель [Официальный репозиторий | Локальный файл].
    - Если Репозиторий:
        - Выпадающий список доступных версий (подгружается асинхронно, если есть интернет).
    - Если Локальный:
        - Поле ввода пути к архиву. (с валидацией)

Логика перехода далее: Версия выбрана или путь указан и валидирован.

## Экран 7: Конфигурация приложения (YDB Config)
- Переключатель [Создать новый конфиг | Загрузить существующий (YAML/JSON)].
    - Если Загрузка: Поле загрузки файла. При загрузке поля ниже заполняются данными из файла.
    - Если Создание (Форма):
        - ydb_domain (string).
        - ydb_dbname (string).
        - ydb_user (string, default: root).
        - ydb_password (password, генератор паролей рядом).
        - ydb_cores_static (number, slider или input).
        - db_cores_dynamic (number).

Валидация: Сумма ядер не должна превышать доступные ресурсы кластера (можно показать предупреждение, если превышает).

Логика перехода далее: Все обязательные поля заполнены, формат данных верен.

## Экран 8: Безопасность (TLS/SSL)
- Переключатель: [Использовать готовые | Сгенерировать].
    - Если Готовые:
        - Путь к папке с сертификатами.

Логика перехода далее: Сертификаты загружены или сгенерированы.

## Экран 9: Процесс установки (Deployment)
- Прогресс-бар общего выполнения.
- Статус каждой задачи: В процессе, Успех, Ошибка.
- Окно консольного вывода с возможностью прокрутки и поиска.
- Кнопка "Стоп/Отмена" (с подтверждением).

Логика перехода далее: Экран блокирует навигацию назад/вперед до завершения процесса. При ошибке процесс останавливается, и собщает об ошибке, кнопка "Далее" заменяется на "К ошибке".

## Экран 10: Результат (Summary)
- Статус: Большой значок (Успех / Провал).
- Ссылка на YDB UI (кнопка "Открыть").
- Кнопка "Завершить" (закрывает мастер) или "Вернуться к началу".
