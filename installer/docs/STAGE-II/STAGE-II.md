# Вторая итерация разработки

## 1. Введение [I]
Показываем краткую информацию о приложении, версию и выбор варианта установки:

- Автоматическая установка YDB (если в директории, где запускается инсталлятор уже есть конфигурационные файлы (inventory.yaml, config.yaml))
- Настройка установки YDB (интерактивный пошаговый мастер)
- Автоматическая установка YDB EM (если в директории, где запускается инсталлятор уже есть конфигурационные файлы)
- Настройка установки YDB EM (интерактивный пошаговый мастер)
- Удаление YDB (переход к экрану 30)
- Удаление EM+YDB (переход к экрану 32)
[ ] - Есть доступ в интернет или нет

Проверка зависимостей (Python, Ansible, ansible-коллекция):
- Для каждой зависимости отображается статус: ✅ установлено / ❌ не найдено
- При отсутствии зависимости доступны три варианта действий:
  1. **Получить инструкцию** - раскрывается блок с командами установки для текущей ОС
  2. **Установить автоматически** - кнопка запускает установку через sudo (требует подтверждения)
  3. **Пропустить** - продолжить без установки (с предупреждением о возможных проблемах)

Тут существующие в директории запуска инсталлятора конфигурационные файлы (inventory.yaml, config.yaml) распаршиваются и автозаполняют поля далее, где это возможно. При отсутствии файлов генерируются шаблонные версии с минимальными значениями при запуске инсталлятора.

## 21. Параметры YDB EM [I]

- Если YDB не установлен — предложение перейти к установке YDB

Параметры:
    - ydb_em_cluster_balancer (FQDN использовать и для CP endpoint)

    - ydb_em_cp_presets (должен быть набор по-умолчанию)

ОБЯЗАТЕЛЬНО ПРОВЕРИТЬ наличие динамического конфига на кластере YDB, и если его нет, то сделать!
