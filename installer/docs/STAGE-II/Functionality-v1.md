**Цель:** Создать работающий пошаговый мастер установки YDB-кластера через Ansible, покрывающий основной сценарий использования - от ввода хостов до успешно запущенного кластера. Реализовать минимально достаточный набор функций, который позволяет реальному пользователю установить YDB-кластер без знания Ansible и без ручного редактирования конфигурационных файлов. Дополнительно реализовать установку YDB EM и удаление YDB / YDB EM.

## Функциональность в v1

### Мультиязычность
- Два языка: **RU** и **EN**.
- Переключатель в шапке на каждом экране.

### Автозаполнение из конфигов
- Парсинг `inventory.yaml` и `config.yaml` при запуске инсталлятора.
- Автозаполнение полей на всех шагах при наличии конфигов.
- При отсутствии конфигов генерируются шаблонные версии с минимальными значениями при запуске инсталлятора.
- Обратная запись: изменения в UI обновляют `inventory.yaml` в реальном времени.
- Автоматический режим (пропуск мастера) при наличии обоих конфигов.

### Технологии
- **Go (Golang)** - API-сервер: бизнес-логика, запуск Ansible, генерация `inventory.yaml` / `config.yaml`, проверка хостов по SSH, генерация TLS-сертификатов.
- **Vue.js 3** - UI-фреймворк: реактивные формы с взаимозависимыми полями (топология → таблицы хостов по ДЦ → диски), динамические таблицы, условный рендеринг шагов.
- **Vite** - сборка и dev-сервер: HMR при разработке, собранный `dist/` раздается Go через `embed.FS` без внешних зависимостей, в dev-режиме проксирует `/api/*` на Go-сервер.
- **Pinia** - стейт между шагами: хранит топологию, хосты, SSH, диски, конфиг, TLS, при переключении топологии данные старой сохраняются и восстанавливаются при возврате, синхронизирует изменения с `inventory.yaml` через API.
- **Vue Router** - навигация: защита маршрутов (переход вперед только после валидации шага), «Назад» без потери данных.
- **WebSocket** (нативный) - стриминг логов Ansible на экранах 9, 24, 31, 33: построчный вывод в консоль, обновление статусов задач и прогресс-бара в реальном времени.
- **Ansible** + коллекция `ydb_platform.ydb` - непосредственная установка и удаление YDB / YDB EM на хостах.

### Установка YDB (основной поток, экраны 1–10)
- **Экран 1 - Введение:** выбор режима (пошаговый мастер / автоматический при наличии конфигов / удаление YDB / удаление EM+YDB), проверка зависимостей (Python, Ansible, ansible-коллекция), чекбокс доступа в интернет. -> Рекомендации по установке python / ansible (или установка автоматические, при возможности через sudo apt install, например) II
- **Экран 2 - Топология:** выбор из `none`, `mirror-3-dc`, `block-4-2`, `bridge-2-dc` с описанием и схемой, для `bridge-2-dc` - вложенный выбор внутренней топологии.
- **Экран 3 - Хосты и SSH:** ввод хостов по ДЦ, настройка SSH (ключ / пароль, jump-host, расширенные параметры), проверка доступности хостов (SSH, время, Python, диски). Проговорить какие возможны конфигурации по ДЦ.
- **Экран 4 - Диски:** отображение дисков, одинаково присутствующих на всех хостах, выбор дисков с предупреждениями, ручной ввод, пропускается при топологии `none`.
- **Экран 5 - Дистрибутив YDB:** выбор версии с официального сайта или указание локальных файлов (package, ydb CLI, ydbd, ydbops, dstool) (официального репозитория, если появится, добавление этого репозитория в систему)
- **Экран 6 - Конфигурация YDB:** ввод обязательных параметров (`ydb_domain`, `ydb_password`, `ydb_cores_static`, `ydb_enforce_user_token_requirement`, `ydb_request_client_certificate`), расширенные настройки (`affinity`), индикатор ресурсов.
автоматически выбираем V1 для всех конфигураций, кроме bridge-2-dc.
- **Экран 7 - Базы данных:** выбор варианта (одна БД / несколько БД / одна БД + YDB EM), параметры (`ydb_database_groups`, `ydb_cores_dynamic`), список БД с именами и хостами, проверка CPU и доступности узлов.
- **Экран 7.1 - Настройки YDB EM** (опционально, если выбран вариант с YDB EM): хосты YDB EM, хосты слотов БД, параметры YDB EM, дистрибутив YDB EM, проверка dynamic config.
- **Экран 8 - TLS:** генерация самоподписанных сертификатов или загрузка готовых с проверкой.
- **Экран 9 - Установка:** генерация `config.yaml`, прогресс-бар, список задач со статусами, консольный вывод через WebSocket, кнопка отмены с диалогом подтверждения.
- **Экран 10 - Результат:** сводка по кластеру при успехе, информация об ошибке, рекомендации и путь к логам при провале.

### Установка YDB EM (отдельный поток, экраны 20–25)
- **Экран 20 - Хосты и SSH для YDB EM:** ввод хостов YDB EM и хостов слотов БД, настройка SSH, проверка доступности хостов.
- **Экран 21 - Параметры YDB EM:** endpoint и БД YDB, параметры YDB EM.
- **Экран 22 - Дополнительные настройки YDB EM**
- **Экран 23 - TLS для YDB EM:** генерация новых / загрузка готовых.
- **Экран 24 - Установка YDB EM:** генерация конфигурации, прогресс-бар, список задач, консольный вывод через WebSocket, кнопка отмены.
- **Экран 25 - Результат YDB EM:** сводка при успехе, информация об ошибке при провале.

### Удаление YDB (поток удаления, экраны 30–31)
- **Экран 30 - Подтверждение удаления YDB:** отображение информации об установленном кластере (хосты, топология, версия), предупреждение об уничтожении данных, поле ввода подтверждения (`DELETE`).
- **Экран 31 - Процесс удаления YDB:** прогресс-бар, список задач полного удаления со статусами, консольный вывод через WebSocket, результат (успех / ошибка).

### Удаление EM+YDB (поток удаления, экраны 32–33)
- **Экран 32 - Подтверждение удаления EM+YDB:** отображение информации об установленных компонентах (YDB EM хосты, YDB хосты, топология), предупреждение об уничтожении данных, поле ввода подтверждения (`DELETE`).
- **Экран 33 - Процесс удаления EM+YDB:** прогресс-бар, список задач полного удаления (сначала YDB EM, затем YDB) со статусами, консольный вывод через WebSocket, результат (успех / ошибка).

## Ограничения первой версии
- **Языки** - только RU/EN, новые языки добавляются файлами в `locales/` без изменения кода.
- **Метод установки** - только Ansible.
- **Тесты** - не входят в v1, структура `test/unit/` и `test/integration/` закладывается сразу.
- **Переустановка** - не реализована (только полное удаление + новая установка).
