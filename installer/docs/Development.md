# Разработка установщика YDB

## Язык и технологии разработки
- Golang для API и самого инсталятора
- Vue.js 3 для интерфейса

## Требования к структуре проекта
- Документация
- Исходный код инсталятора (API)
- Исходный код интерфейса
- Тесты для API
- Тесты для интерфейса
- Тесты для инсталятора

Этапы:
1) Установка через ansible
2) Установка через ansible + пакеты (deb / rpm)
3) Установка без ansible через пакеты
