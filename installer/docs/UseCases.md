# Текущие проблемы, мешающие быстрой установке YDB
Общие проблемы:
- Необходимость погружения в терминологию YDB
- Необходимость погружения в терминологию ansible
- Ограничения текущей реализации коллекций и сценариям
- Привязка к ограничениями python и ansible

## Проблемы с YDB ansible коллекцией
- Трудности с проверкой актуальности python
- Трудности с проверкой и установкой актуальной версии ansible
- Трудности с проверкой и установкой актуальной версии ansible коллекции
- Ошибки при создании config.yaml и настроек ansible
- Понимание и правильная интерпретация ошибок ansible при сбоях во время установки.
Примечание: в ansible коллекции есть часть проверок, но чтобы их выполнить, в начале надо уже иметь python, ansible и настройки. 

## Потенциальные трудности с быстрой установкой YDB EM
- Необходимость предварительной установки YDB с определенными настройками
- Настойка инвентори

# Предлагаемое решение
Все множество проблем можно разделить на две группы:
- Проблемы с предварительной подготовкой к установке
    - Проблемы с подготовкой python, ansible
    - Проблема с подготовкой узлов и информации о них
    - Проблема с подготовкой конфигураций YDB / YDB EM / Ansible
    - Изучение терминологии YDB / YDB EM
- Проблемы с процессом установки
    - Запуск плейбуков
    - Интерпретация вывода ansible
    - Формирование корректного набора данных для обращения в поддержку
Исходя из этих групп можно предложить следующие решения:
1. Создание инсталятора (локального установщика), который позволит последовательно собрать у пользователя нужную информацию, проверить ее и подготовить окружение для запуска установки YDB / YDB EM, а затем обеспечить запуск установки и сопроводить эту процедуру.
2. Доработать в ansible коллекции обработку аварийных ситуаций и добавить вывод справочной информации о том, как их понимать и решать.

Например, средствами Ansible проблематично выявить расхождение во времени между узлами, на которых будет проводиться установка YDB, но можно такую функциональность заложить в инсталятор.

# Требования к инсталятору (технические)
- Наличие графического интерфейса с возможностью копирования настроек в интерфейс
- Запуск на сервере, с которого будет вестись установка
- Возможность работы:
    - В закрытом контуре
    - В открытом контуре
    - Подготовка к закрытому контуру

# Требования к инсталятору (функциональные)
- Проверка python, если нет или не подходит - рекомендации по тому, как установить
- Проверка ansible, если нет или не подходит - рекомендации по тому, как установить
- При установке YDB EM и отсутствии YDB - установка YDB
- Проверка доступности узлов, на которые будет установка
- Проверка доступных дисков
- Интерактивный выбор топологии
- Использование уже готового config.yaml
- Мультиязычность интерфейса (русский, английский, китайский, хинди, испанский, арабский, французский)
